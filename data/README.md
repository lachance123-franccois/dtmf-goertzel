# Données personnelles (optionnel)

Le projet tourne entièrement sans ce dossier : `main.m` génère ses propres données de test avec vérité terrain.

Pour tester sur vos propres fichiers (enregistrements, photos...), placez-les ici sous les noms indiqués dans la section « Lancer le projet » du README principal. Le `.gitignore` les exclut du dépôt : ajoutez-les volontairement avec `git add -f` si vous voulez les publier, et seulement si vous en avez le droit.
